Scryer Plugin Settings

This Alpha targets Jellyfin 10.11.x web clients and was tested against Scryer 0.19.7. Compatibility is decided by the live preflight checks below, not by a version number. Each person connects their own Scryer account; do not enter a shared Scryer API key here.
